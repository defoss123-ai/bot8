# MEXC Flipping Bot

Асинхронный бот для торговли на MEXC (USDT-M), с управлением парами, генерацией сигналов, трейдинг-модулем, TUI-интерфейсом и дублированием логов в БД/файл.

## Требования

- Python 3.9+

## Установка

1. Создайте и активируйте виртуальное окружение:

```bash
python -m venv .venv
source .venv/bin/activate
```

2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` в корне проекта:

```env
MEXC_API_KEY=your_api_key
MEXC_SECRET=your_secret
```

## Запуск

```bash
python main.py
```

## Кратко про интерфейс

- Нажмите `m`, чтобы открыть меню.
- Используйте стрелки для навигации по пунктам.
- Нажмите `Enter` для выбора.

## Структура проекта

- `main.py`
- `pair_manager.py`
- `signal_generator.py`
- `trader.py`
- `interface.py`
- `db_logger.py`
- `requirements.txt`
- `.env` *(не включать в репозиторий)*
- `operations.log` *(создаётся автоматически)*
- `trading_bot.db` *(создаётся автоматически)*

## Важно по безопасности

Не используйте бота на больших депозитах без тщательного тестирования на демо/минимальных объёмах и без дополнительной валидации торговой логики под ваши условия.
